# Ahorcado en Python

Proyecto desarrollado en Python que incluye un juego del ahorcado, almacenamiento de datos y análisis estadístico.

---

## Funcionalidades

- Juego interactivo por consola
- Sistema de rondas
- Control de intentos y dibujo del ahorcado
- Dificultad (fácil, normal, difícil)
- Pistas y letras falladas

---

## Persistencia

Los datos se guardan automáticamente en:

- data/games.csv → partidas
- data/rounds_in_games.csv → rondas
- data/resumen_partida.txt → resumen final

---

## Análisis de datos

Notebook en:

notebook/estadisticas.ipynb

Incluye:

- Distribución de palabras
- Usuarios únicos
- Top 5 jugadores
- Puntuaciones
- Gráficos con matplotlib y plotly

---

## Opcionales

- Evolución de usuario
- Exportación a Excel
- Gráficos interactivos
- Filtro por usuario
